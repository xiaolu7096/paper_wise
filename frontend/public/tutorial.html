PAPERWISE GUIDE

从上传论文到整理笔记

按照下面 6 个步骤即可完成一次完整阅读。截图可点击查看原图；界面中的论文名称和模型名称仅作为示例。

上传阅读配置速读解释整理
01

上传并打开论文

PDF 上传后会立即进入阅读器，解析任务在后台继续执行。

  1. 在左侧“论文库”点击“上传”，选择本地 PDF 文件。
  2. 论文会立即出现在列表中；处理中仍可阅读原始 PDF。
  3. 进度胶囊显示解析状态。状态变为“已就绪”后，问答和 AI 速读可用。
02

翻页与调整页面

PDF 工具栏保持纯图标，通过页码、适配和缩放控制阅读视图。

  1. 使用左右箭头翻页，也可以输入页码后按 Enter 或点击输入框外提交。
  2. 横向双箭头用于“适合宽度”，对角箭头用于“适合页面”。
  3. 使用减号和加号缩放；中间百分比显示当前缩放比例。
03

配置 AI 模型

以 DeepSeek 文本模型为例；模型地址、模型名和 API Key 均以服务商控制台为准。

  1. 打开左侧“API 配置”，在“文本模型”中勾选“启用”。
  2. DeepSeek 示例 Base URL 填写 https://api.deepseek.com。
  3. 填写控制台提供的当前模型名和 API Key，然后保存设置。
  4. 已保存的密钥不会回显；再次保存启用中的模型时需要重新输入 API Key。

DeepSeek 在本教程中仅作为文本模型示例，用于问答、文本解释和速读。区域截图解释需要在“视觉模型”中配置支持图片输入的 OpenAI-compatible 服务。

04

生成 AI 速读报告

速读会生成一份带来源引用的连续 Markdown 报告。

  1. 确认论文状态为“已就绪”，并已配置文本模型。
  2. 打开右侧“速读”tab，点击“生成速读报告”。
  3. 生成完成后可点击引用跳转原文；右上刷新图标用于重新生成。

生成时间取决于论文长度和模型服务。生成过程中按钮会锁定，请等待完成，不需要重复点击。

05

解释文字或页面区域

文本选择适合段落和术语，区域框选适合图表、公式与混排内容。

  1. 直接拖动选择 PDF 文字，右侧会自动切到“解释”；可选择解释、总结或继续追问。
  2. 点击工具栏的区域框选图标，在 PDF 上拖出矩形区域，再输入问题并发送。
  3. 区域解释依赖视觉模型；按 Esc 可退出框选模式。
  4. 满意的解释可以保存，之后会出现在“笔记”tab 中。
06

继续问答并整理笔记

问答用于围绕整篇论文检索，笔记用于沉淀阅读结果并返回原文。

  1. 在“问答”中输入论文相关问题；论文必须已就绪且文本模型可用。
  2. 回答下方的来源标签可跳转到对应 PDF 页，便于核对原文。
  3. 在“笔记”中添加普通笔记，也可以保存文本解释和区域解释。
  4. 带页码的笔记可以点击页码返回原文；删除仅影响当前笔记，不会删除论文。

论文问答

每篇论文拥有独立会话。清空会话前会要求确认，引用页码始终来自当前论文。

笔记整理

普通笔记、文本选区和区域截图使用不同标签，切换论文时不会混入其他论文内容。

完成以上步骤后，即可形成“阅读原文 → AI 辅助理解 → 核对来源 → 保存笔记”的完整流程。模型请求会把必要的文本片段或区域截图发送到你配置的模型服务。
